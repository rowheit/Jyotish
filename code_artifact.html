कॉम्प्युटरवर Local LLM (Ollama) कसे सेट करावे? (मराठीत सोप्या टिप्स)

तुमच्या वैयक्तिक PC वर Ollama द्वारे पूर्णपणे मोफत आणि प्रायव्हेट एआय मॉडेल चालवण्यासाठी खालील स्टेप्स वापरा:

  1. पहिले ollama.com वरून Ollama सॉफ्टवेअर डाउनलोड करा.
  2. कमांड प्रॉम्प्ट (CMD / Terminal) उघडा आणि मॉडेल डाउनलोड करा: ollama run llama3
  3. ब्राउझरमधून स्थानिक कनेक्ट (CORS Header allow) करण्यासाठी ही कमांड चालवून Ollama सर्व्हर चालू करा: OLLAMA_ORIGINS="*" ollama serve
  4. वेबसाईटवरील वरील "Local LLM" बटणावर क्लिक करा आणि 'सुरू करणे' निवडा.
